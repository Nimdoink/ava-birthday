# Ava's 21st Birthday Page

A tiny pink-and-gold birthday page for Ava. It shows her birthday message with confetti falling in the background. There are no accounts, photo uploads, or setup tools needed for the page itself.

## Put the page on GitHub Pages

These steps use the GitHub website. You only need the four files in this folder: `index.html`, `styles.css`, `app.js`, and `README.md`.

1. Go to [github.com](https://github.com) and sign in. If you don't have an account, choose **Sign up** and follow the steps.
2. Click the **+** button in the top-right corner, then click **New repository**.
3. In **Repository name**, type `ava-birthday`.
4. Choose **Public** so people with the link can see the page. Leave the other choices alone, then click **Create repository**.
5. On the new repository page, click **Add file**, then **Upload files**.
6. Drag the four files named above from this folder into the big upload box. Make sure `index.html` is included; that is the page GitHub opens first.
7. Scroll down to **Commit changes** and click the green **Commit changes** button.
8. At the top of the repository, click **Settings**. If you don't see it, look for **…** or **More**.
9. In the left menu, click **Pages**.
10. Under **Build and deployment**, set **Source** to **Deploy from a branch**. Set the branch to **main** and the folder to **/(root)**, then click **Save**.
11. Wait a minute or two. Refresh the **Pages** screen until GitHub shows that your site is live.

Your page link will look like this:

`https://YOUR-GITHUB-USERNAME.github.io/ava-birthday/`

Replace `YOUR-GITHUB-USERNAME` with the username you see on your GitHub profile. For example, if your username is `ava123`, the link is `https://ava123.github.io/ava-birthday/`. You can send that link in a text message. To make words clickable in a place that supports links, write: `[Open Ava's birthday page](https://YOUR-GITHUB-USERNAME.github.io/ava-birthday/)`.

If you give the repository a different name, use that name instead of `ava-birthday` in the link. Whenever you change the page later, upload the changed file again and click **Commit changes**; GitHub Pages will update the site.
